# 隐私说明

MusicTagFixer 是本地桌面工具，不设置项目服务器，也不包含遥测、广告 SDK 或账号系统。

## 本地处理

- 音频内容在本机读取和写入；
- 默认输出到用户选择的新目录；
- 原文件默认不修改；
- 上次输出目录保存在 `%APPDATA%\MusicTagFixer\settings.json`。

## 在线查询

启用在线补全时，程序会向第三方音乐服务发送歌名、歌手和必要的时长信息，用于查找元数据、封面和歌词。程序不会主动上传完整音频文件。

第三方服务可能按照其隐私政策记录 IP 地址、请求参数和访问日志。用户可以关闭在线补全，仅整理本地已有标签。

## 日志

日志显示在程序窗口中，不会自动上传。提交 Issue 前请检查并删除本地路径、真实姓名或其他不希望公开的信息。
