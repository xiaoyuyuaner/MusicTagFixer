# MusicTagFixer

一个面向个人音乐文件的批量标签、封面与歌词补全工具，重点解决音乐云盘上传后出现的歌手未知、专辑缺失、封面不显示、歌词缺失、繁体标签和乱码等问题。

> 本项目不是网易云音乐、QQ音乐、酷狗音乐、Apple Music 或其他平台的官方产品，也不提供音乐下载、版权绕过或账号自动化功能。

## 它解决什么问题

许多来源不同的 MP3、FLAC、M4A 文件存在以下问题：

- 文件名正确，但内嵌歌手或专辑标签缺失；
- 本地播放器能显示封面，上传云盘后却无法识别；
- 标签使用繁体中文或存在 GBK/UTF-8 乱码；
- 同名歌曲被匹配到翻唱、现场或其他歌手版本；
- 批量处理后难以区分完整结果和待人工确认项目。

MusicTagFixer 会读取文件名和原标签，从多个元数据来源查找可信候选，并以兼容性较好的方式重新写入音频标签。原音频默认不会被覆盖。

## 当前支持范围

目前主要面向**上传至网易云音乐“我的音乐网盘”前的文件修复**，用于提高歌曲名称、歌手、专辑、内嵌封面和歌词被网易云音乐正确识别的概率。由于云端还会进行异步匹配，上传后部分信息可能需要等待一段时间才会显示。

项目目前不会直接登录或操作网易云音乐账号，也不能绕过版权、音频指纹或平台风控限制。

## 主要功能

- 支持 MP3、FLAC、M4A，并根据文件内容识别真实格式；
- 境内来源优先：网易云音乐 → QQ音乐 → 酷狗音乐；
- Apple Music、LRCLIB、MusicBrainz、Cover Art Archive 作为备用来源；
- 补充歌名、歌手、专辑、年份、曲号、封面和歌词；
- 中文繁体转简体，修复常见乱码；
- 清除 `[51ape.com]`、微信公众号等文件名水印；
- “歌手 - 歌名”文件名可强绑定歌手，避免误用翻唱版本；
- 保留已有封面，支持同目录封面和手动指定封面；
- 输出自动分为 `处理成功` 和 `待复查`；
- 支持批量暂停与继续；
- 支持自定义输出目录，并自动记住上次选择；
- 默认复制到新目录，不覆盖原文件。

## Windows 用户

推荐从 GitHub Releases 下载 `Windows免安装版.zip`：

1. 完整解压 ZIP；
2. 双击 `音乐标签与云盘修复工具.exe`；
3. 添加歌曲或文件夹；
4. 选择输出目录；
5. 点击“开始修复”。

免安装版不需要 Python。请勿单独移动 EXE，旁边的 `_internal` 文件夹也是程序的一部分。

## 从源码运行

需要 Python 3.10 或更高版本：

```powershell
git clone <repository-url>
cd MusicTagFixer
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python music_tag_fixer.py
```

## 匹配安全规则

歌名和歌手属于身份字段。当本地文件名或标签已经提供可信值时，网络结果只能补充缺失信息，不得随意改名。

当文件名符合 `歌手 - 歌名` 格式时，候选歌手必须匹配，否则该候选会被淘汰并继续查询下一个来源。类似 `TANK 吕建忠` 与 `Tank` 的艺名/本名组合可兼容匹配。

建议首次批量处理时先抽查结果。现场版、翻唱版、重新录音版和同名歌曲仍可能需要人工确认。

## 隐私与网络访问

- 音频文件只在本机读取和写入，不会上传到本项目的服务器；
- 在线查询只发送用于搜索的歌名、歌手、时长等必要信息；
- 项目不收集账号、播放记录或遥测数据；
- 具体访问的服务及注意事项见 [隐私说明](docs/PRIVACY.md)。

## 已知限制

- 音乐平台的非公开接口可能随时调整或限制访问；
- 在线数据库不一定收录小众歌曲和非正式现场录音；
- 云盘平台是否采用内嵌封面/歌词由平台决定；
- 本工具不能解决平台版权、音频指纹或账号风控导致的上传拒绝；
- 当前正式构建目标为 Windows 10/11，macOS 尚未提供安装包。
